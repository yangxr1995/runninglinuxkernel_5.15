# TCP Server/Client 测试程序

## 编译

```bash
make
```

## 运行

### 1. 启动服务器

在终端中运行：
```bash
./server
```

服务器将在端口8888上监听，只接收数据而不发送响应。

### 2. 启动客户端

在另一个终端中运行：
```bash
./client <server_ip> [message_size] [send_interval_ms]
```

参数说明：
- `server_ip`: 服务器的IP地址（例如：127.0.0.1）
- `message_size`: 每个报文的大小（字节），默认1024字节
- `send_interval_ms`: 发送间隔（毫秒），默认1000毫秒

### 示例

#### 基本用法（默认参数）：
```bash
./client 127.0.0.1
```

#### 自定义报文大小和发送间隔：
```bash
# 发送512字节报文，每500毫秒发送一次
./client 127.0.0.1 512 500

# 发送2048字节报文，每100毫秒发送一次
./client 127.0.0.1 2048 100
```

## 特性

### Client端特性：
- 通过命令行参数配置服务器IP、报文大小和发送间隔
- 自动禁用Nagle算法（TCP_NODELAY）
- 持续发送数据直到手动终止（Ctrl+C）
- 显示发送统计信息

### Server端特性：
- 监听端口8888
- 接受多个客户端连接
- 只接收数据，不发送响应
- 显示接收统计信息
- 支持每个连接的独立统计

## 注意事项

- 客户端会持续发送数据，使用Ctrl+C终止
- 服务器可以处理多个客户端，但会逐个处理
- 报文大小限制：1 - 65536字节
- 发送间隔必须为非负整数（毫秒）
